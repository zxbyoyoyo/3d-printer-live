# 竖屏与互动动效（用户已确认）

本轮实现四项：竖屏近景、成品底座文字清晰度、小心心礼物出场、成品分数揭晓。保留已保存的机位与方向，不自动覆盖用户设置；增加「竖屏直播」一键配置 1080×1920 / 30 FPS / MSAA4 标准画质和打印机近景。

根据用户截图反馈，移除底部常驻头像/昵称/进度面板及其开关，昵称和分数只显示在成品底座。礼物提醒必须画进 WebGL 输出画布，确保独立直播小窗/OBS 看到相同内容。底座文字以高清 CanvasTexture 生成，使用不受暗光影响的材质；礼物短时提醒通过正交层叠加。降低头像表面盖层反光，保持原始头像比例，不宣称修复低分辨率源图。

礼物出场以 1.8 秒小心心双拍和有限数量飘心表现，不触发重复打印或重复语音；只在新的礼物任务开始时出现，多张礼物的后续副本不重复弹卡。成品完成后数字在 0.7 秒内计数至实际分数，停留至 1.6 秒后转运。动画使用真实时间，暂停冻结、跳过/礼物抢占清理旧动效；同一结果只记录一次。关闭互动动效后恢复简洁显示。

实现通过独立 presentation-state.mjs（纯状态）、live-presentation.mjs（仅短时礼物 GPU 叠加）、portrait-framing.mjs（机位）组织；中英文入口使用共享模块。测试覆盖动画状态、帧率独立、暂停、跳过、捕获合成、常驻面板移除和现有礼物插队。浏览器检查横竖屏、独立窗口和素材。短时本机压力观察与长时间真实直播验证分开报告。
