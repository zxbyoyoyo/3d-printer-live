# Mac 直播优化版

基于上游 MIT 项目保留 Three.js 打印机和 Windows 桌面入口。在 macOS 使用 Python 本机服务 + Chrome 窗口，不依赖 WebView2；支持独立登录配置、打开直播间、启动和停止 Node.js 数据桥。浏览器查找兼容系统和用户 Applications。修复选中端口被覆盖以及从其他工作目录启动的问题。

关注感谢独立于关注打印，默认开启，可在语音设置关闭；中文与英文均支持。保持礼物和进场播报，使用系统 TTS。

提供白色手套透明 PNG、手势 GIF/WebP、小心心引导 GIF/WebP、黄字规则牌透明 PNG。复用上游已有礼物图标，原创手势用内置 ImageGen 生成。素材网页支持下载和透明浏览器叠加链接。默认规则明确为评论 666 小图一张、小心心大图一张、啤酒两张、棒棒糖三张；规则叠加可读取当前设置，导出的静态素材注明默认规则。

验证包含 Python 服务/端口/启动参数、Node 解析及语音回归、浏览器实际渲染和素材透明度/循环帧检查。真实直播需用户扫码登录和提供自己的直播间，不上传本地登录态、房间号、头像缓存或日志。发布到 zxbyoyoyo 的上游 fork。
