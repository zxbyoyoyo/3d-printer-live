# Mac live implementation plan

**Goal:** 在用户 M4 Mac 上提供可启动的头像打印机、关注答谢和直播叠加素材。

**Architecture:** Python 本机控制服务配合 Chrome 与 Node CDP 数据桥；静态前端沿用上游。独立素材页面复用透明图标和原创手势。

**Tech Stack:** Python 3.12、Node 24、Three.js、浏览器 SpeechSynthesis、Pillow/FFmpeg。
