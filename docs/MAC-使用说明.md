# Mac 直播优化版

适用于 Apple Silicon Mac（M 系列）和 Intel Mac。已在 macOS 15.5 / M4 / 32 GB 上验证本机服务、Chrome 3D 演示、中文语音和素材页面。

## 启动

1. 安装 Python 3 和 Node.js 22 或更新版本（推荐 Node 24 LTS），安装 Google Chrome。此 Mac 路径已有对应软件。
2. 下载仓库 ZIP 并解压，双击 `start-mac.command`，保持弹出的终端窗口开启。
3. 若系统没有把 `.command` 作为可执行文件，在终端进入解压目录，执行 `zsh start-mac.command`。不需要安装 pywebview 或 WebView2。
4. 浏览器会打开打印台。也可在终端执行 `python3 launch.py --browser`。只启动服务用 `python3 launch.py --server-only`，地址以终端输出为准，默认 8080，冲突则尝试备用端口。

本版是 Chrome 浏览器窗口，不是签名的原生 macOS App。Windows 仍可使用原有 `.bat` 和 WebView2 桌面入口。

## 接入自己的直播间

在「直播连接」填入房间号或 `https://live.douyin.com/房间号`，点「打开直播间窗口」。在独立 Chrome 窗口自行扫码登录，进入直播间后点「开始抓取」。看到数据桥连接且真实互动计数变化后再开播。点「停止抓取」会停止此服务启动的数据桥，不会自动再次拉起；再次点开始可恢复。

独立窗口使用项目下 `.bridge-profile/`，与平时浏览器登录配置分开。登录态、房间号、观众缓存和运行日志已加入 Git 忽略。本次未替用户扫码或进入真实直播间，平台当前页面和协议仍需要开播前实测。

## 语音

先点击「试听女声」或「模拟关注」。浏览器需用户点击才允许有声播放。声音由系统中文语音合成，不调用付费配音接口；可以选择音色和语速。

「打印规则 → 语音播报」里，礼物答谢、进场欢迎、关注感谢分别开关，关注感谢不依赖「关注打印」开启。

中文文案改为短句、随机轮换、同类相邻不重复：

- 感谢小明送出的小心心！
- 谢谢小明的小心心，爱你哦！
- 感谢小明的小心心，太感谢啦！
- 谢谢小明支持，小心心收到啦！
- 感谢小明关注了我，我也会回关你的哈！
- 谢谢小明的关注，爱你哦！

单个礼物省略数量，多个保留，例如「谢谢小明的3个小心心，爱你哦」。文案在 `gift-speech.mjs` 的 `text`、`follow`、`welcome` 中修改。「回关」只是用户指定的播报文案；程序不会替主播操作账号关注。

## 直播素材

打印台右侧「直播素材 ↗」进入素材页。素材也放在 `assets/overlays/`：

| 文件 | 用途 |
|---|---|
| `point-down.gif` / `.webp` | 360 × 480，向下指手势循环动图 |
| `heart-reminder.gif` / `.webp` | 480 × 660，小心心跳动 + 提醒文案 + 手势 |
| `glove.png` | 高清透明白手套，原创生成 |
| `heart.png` | 高清透明小心心，原创生成 |
| `print-rules.png` | 1200 × 1040，透明黄色默认规则牌 |

GIF 有透明背景，WebP 保留柔和半透明边缘。若直播软件不支持透明 GIF，OBS 使用浏览器来源可获得平滑边缘。添加地址：

- 手势：`http://127.0.0.1:8080/overlay.html?mode=pointer`，尺寸 360 × 480。
- 心心：`http://127.0.0.1:8080/overlay.html?mode=heart`，尺寸 480 × 660。
- 规则：`http://127.0.0.1:8080/overlay.html?mode=rules`，尺寸 600 × 520。

若服务换了端口，直接在素材页复制地址。手势应由主播根据直播平台手机画面的位置调整；素材不能直接改变抖音手机 App 的礼物按钮。

默认规则：评论 666（其他评论也会触发）→ 小图 1 张；小心心 → 大图 1 张；啤酒 → 大图 2 张；棒棒糖 → 大图 3 张。下载动图/默认规则 PNG 固定使用这一组文案。

同一 Chrome 浏览器打开的透明叠加页会跟随主页面的打印规则实时更新。OBS 有独立浏览器存储，默认使用上面的规则；如果改了数量或大小，请在素材页点「当前规则 PNG」重新导出，再放进 OBS，以保证观众看到的规则与实际一致。电脑服务要保持开启，浏览器来源才能加载。

## 画质与采集

M4 建议先以 1080 × 1920、30 FPS 和标准画质开播，再观察实际采集流畅度。4×/8× 内部渲染开销较大；这是起始建议，未进行长时间直播压力测试。点「弹出画面」可输出干净场景，OBS 采集场景窗，声音仍由主页面播放。需要给 OBS 的屏幕录制权限由用户自行授权。

## 验证和重建

```sh
python3 -m unittest test_mac test_scene_relay -v
node --test *.test.mjs
zsh -n start-mac.command
```

素材生成脚本需要 Pillow（仅重新生成时需要），执行 `python3 scripts/build-overlays.py`。macOS 自动寻找苹方，其他系统设置 `OVERLAY_FONT` 指向粗体中文字体。
